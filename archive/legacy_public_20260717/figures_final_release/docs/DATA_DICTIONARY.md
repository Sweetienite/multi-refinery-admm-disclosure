# 数据文件说明

- `fig1a_system_total_benefit.csv`：独立运营、中心化协同和 ADMM 分布式目标函数值。
- `fig1b_objective_gap.csv`：ADMM 与中心化参考的目标函数值差异。
- `fig2_admm_trace.csv`：60 次严格参考运行的完整迭代轨迹；保留各流股、残差、容量分配和目标函数值。
- `fig3_compensation_interval.csv`：A 向 B 支付的个体理性可行区间。
- `fig4_utility_exposure.csv`：图 4 使用的主点数据。
- `fig4_exposure_components.csv`：五个可观察暴露分量及主权重总分。
- `fig4_weight_sensitivity.csv`：五套权重方案下的暴露分数与降低率。
- `data/source/`：用于追溯与复核的原始冻结文件。
