# 参数定义

当前论文使用的唯一公开参数源是 `configs/paper_public_parameters_20260806.yaml`。

- 主 ADMM：`rho=0.1`，最大 10,000 次，原始/对偶残差阈值均为 `1e-7`。
- 披露扫描：三个固定 seed（20260511、20260512、20260513）、五个 rho 值（0.1、1、10、100、1000），每次最多 500 轮。
- 分阶段量化：rho=1，宽度依次为 0.75、0.375、0.125 kt。
- 配置量分桶：边界展示宽度 0.25 kt；正式主结论使用 rho=10、0.01 kt 和区间中点代表值。
- 主评分权重为 0.25/0.20/0.20/0.20/0.15；另给出四组替代权重。
