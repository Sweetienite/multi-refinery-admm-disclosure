# 方法、数据与适用边界

中心化模型提供协同参考；ADMM 在非负共享容量集合上做欧氏投影，避免把比例缩放当作欧氏投影。两种披露机制只改变协调消息的数值分辨率和可见字段，不等价于密码学隐私机制。

主评分为：

`S = 0.25 E_exact + 0.20 E_stream + 0.20 E_temporal + 0.20 E_capacity + 0.15 E_aggregate`。

其中五个分量分别衡量精确数值直接可见度、活跃流股标识直接可见度、时序热点可恢复度、容量压力状态恢复度和聚合配置轨迹可重构程度。分数越高表示在既定公开字段与恢复规则下越容易观察或恢复。

3.78 kt 仅表示相对独立基准的正向配置增量合计；它不表示企业间真实管输量。结论适用于公开基准系数和本文定义的消息字段，不外推到真实企业安全性或生产决策。
