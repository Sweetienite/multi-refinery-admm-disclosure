# 方法、数据与适用边界

中心化线性规划提供协同参考；ADMM 在非负共享容量集合上采用欧氏投影，而非历史比例缩放。两种披露机制只改变协调消息的数值分辨率和可见字段，不等价于密码学隐私机制。

主评分为：

`S = 0.25 E_exact + 0.20 E_stream + 0.20 E_temporal + 0.20 E_capacity + 0.15 E_aggregate`。

五个分量依次衡量精确数值直接可见度、活跃流股标识直接可见度、时序热点可恢复度、容量压力状态恢复度和聚合配置轨迹可重构程度。分数越高，表示在既定公开字段与恢复规则下越容易观察或恢复。五组权重敏感性结果见 `results/table5_weight_sensitivity_authoritative.csv`；每一组中分阶段量化的评分均低于配置量分桶，且两者都低于未控制披露基准 1.000。

3.78 kt 仅表示相对独立基准的正向配置增量合计，s391 的 48.7% 是其中占比；两者均不表示企业间真实管输量或收益贡献。结论只适用于公开基准系数、本文消息字段和锁定参数，不外推到真实企业安全性或生产决策。
